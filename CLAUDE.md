# Claude Code Configuration

This repository contains a collection of standalone tools and utilities.

## Agent Configuration

See [agents.md](./agents.md) for AI agent behavior and context configuration.

## Repository Structure

- Each tool lives in its own directory with a dedicated README
- Tools are designed to be simple, standalone applications
- No complex build systems - tools should work directly in the browser

## Guidelines

- Keep tools simple and focused on a single purpose
- Use vanilla JavaScript with minimal dependencies
- Prefer CDN-hosted libraries when external dependencies are needed
- Each tool should be self-contained and work via GitHub Gist preview
